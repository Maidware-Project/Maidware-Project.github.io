download Maidshare

Maidshare sends files and links from your linux PC to your phone - and takes files back the other way. it is a command-line tool, not an app: no store listing, no account, and nothing to install on the phone.

on a slow or capped connection? the whole source archive is about 25 KB - smaller than a single photo, and it is plain text: no binaries, no images. this page itself loads nothing from outside, so there are no fonts, trackers or analytics to wait on. take the tar.gz over the zip, and if you use git, clone with --depth 1.

two ways to get it

1. take the source archive

a zip or tar.gz of the source. no git needed - unzip it and follow the install step.

.zip · about 31 KB .tar.gz · about 23 KB

2. or clone it with git

$ git clone --depth 1 https://github.com/Maidware-Project/Maidshare
$ cd Maidshare

install

one script copies the tool and its icon, and tells you which send backends your machine already has. 

$ bash install.sh --check   # dry run: shows what it would copy
$ bash install.sh           # do it - existing files are backed up first

the installer downloads nothing: every dependency comes from your distro's own packages. it never symlinks, and it asks before it touches anything.

the PC side: getting files back

the same install works in both directions on your computer. maidshare --receive starts a small page on your own network and prints a QR code and a token link. open either one on your phone's browser and the file uploads straight to your PC, landing in ~/Downloads/MaidShare. any other computer on the same network can use that link too, so it doubles as a PC-to-PC hop. the page expires by itself, and nothing leaves your local network. 

$ maidshare --receive           # qr + browser upload, phone or another pc
$ maidshare --receive --time 5  # close it again after 5 minutes

what you need

  • a linux PC - this is the computer half; the phone needs no app at all
  • to send: KDE Connect, or adb, or just wifi. Maidshare picks whichever is there and tells you which one it used
  • to receive: python 3, already present on nearly every distro

read it before you run it. the security notes say what this site and the tools do and do not do. found a problem? write to maidwareproject@proton.me first, rather than opening a public issue.
