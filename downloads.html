downloads

every tool comes as real packages (.deb, .rpm, Arch) built from that tool's release tag. the installer was already made to stage to a system prefix, so the packages drop the same files the installer would. nothing here fetches at load.

MaidShare

send files and links from linux to an android phone - and back. no phone app.

.deb .rpm arch

install: download the package for your distro, then install it with your package manager. the packages mirror what each install.sh would do: they drop the same files (no symlinks), write system metadata, and tell the tools to use /usr paths.
