do you want to help?

are you a developer? do you have a little time? that is worth more here than money ever will be.

we don't take donations

we take help. a small tool stays alive because someone read the code and sent a fix, not because someone paid for it. if you want to keep open source going, the useful thing is your time.

what actually helps

  • shell and python patches: each repo's test suite shows the way
  • run a tool on your distro and tell us what broke, with the console output
  • a hand-written translation, if you speak another language
  • docs that read like a person wrote them, because a person should

help us do translations

we at maidware project need help with translations, and we want translators to help us. english is the only language here right now, on purpose. we'd rather ship none than machine-made strings that read badly to the people they're for. if you speak another language, a hand-written set of strings is welcome.

say hello, send a patch, or offer a translation: maidwareproject@proton.me

keeping open source alive is worth the effort, and it only works when people pitch in.
