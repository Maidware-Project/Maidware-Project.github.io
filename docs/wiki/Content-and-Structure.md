# Content and structure

## Key pages
- `index.html` — landing page
- `guides/index.html` — tool guides and troubleshooting
- `faq/index.html`, `performance/index.html`, `contributions/index.html`, `conduct/index.html`, `changelog/index.html`

## Styling and behavior
- `css/style.css` — layout and theme definitions (CSS variables)
- `js/theme-boot.js` — applies stored theme/settings early
- `js/main.js` — UI behavior (menus, nav, copy buttons, TOC highlighting)
- `js/i18n.js` — translation scaffolding (English-only currently)

## Editing tips
- Keep copy clear and factual; avoid machine-translated content
- Preserve accessibility/readability (contrast, semantic structure)
- When adding sections in guides, add/update corresponding TOC anchors
- Maintain theme consistency and update theme lists where required
