# Local development

## Preview locally
```sh
python3 -m http.server 8000
# open http://localhost:8000
```

## Checks
```sh
python3 tests/check.py
```

## Editing workflow
- Edit HTML/CSS/JS files directly
- Refresh browser to verify changes
- Keep legacy redirect pages working when renaming/moving content URLs
- Validate links/assets/anchors before pushing when possible
